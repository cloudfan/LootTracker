# Loot Tracker

A World of Warcraft: Forever addon (`## Interface: 16001`, Lua 5.1). Standalone: it depends on no other addon; it bundles LibStub, CallbackHandler-1.0 and LibSharedMedia-3.0 under `LootTracker/Libs` (loaded first; `## OptionalDeps: LibSharedMedia-3.0, SharedMedia` so another copy loads before it). The addon folder is `LootTracker/`. It is the standalone version of CRPGui's Loot Tracker module (cloudfan/PillarsUI, `CRPGui_LootTracker`, since 2.0.0; before that Pillars UI's `PillarsUI_LootTracker`): `Names.lua`, `Tracking.lua`, `Auction.lua`, `Data.lua` and `Window.lua` are that module's files with `local API = ns.API` and the global names renamed (`LootTracker...`, the popup `LOOTTRACKER_RESET`); keep them in step with the module. Where they differ: `Data.lua` hooks the item tooltips itself (`TooltipDataProcessor.AddLinePostCall` on the Sell Price line, `AddTooltipPostCall` for items without one) instead of CRPGui's tooltip parts; `Window.lua` keeps its own place (`positions.lootTracker`: `{ "TOPLEFT", "BOTTOMLEFT", x, y }`, saved when a drag or resize ends) instead of CRPGui's mover, and has no Data Text tokens.

## Layout

- `LootTracker/Core.lua`: `ns.API`, the framework calls those files make, written for this addon alone: settings by section (`RegisterDefaults`, `Get` / `Set`, `ClearSection`; only changed values kept, in `LootTrackerSettings`), events (`On`, one frame) and messages (`Listen` / `Fire`), `OnReady`, `Print`, `IsSecret` / `Plain`, colors (`ResolveColor`, color settings `{ preset = ... }`), media through LibSharedMedia (`API.LSM`; `MediaList` is its list, `Fetch` its file; the game's own fonts, bar textures and backgrounds in `MEDIA` are registered into it where it lacks their file, and still resolve by our names; with no LSM, `MEDIA` alone; `ApplyFont`), a bordered panel (`CreateInsetBorder`: a tooltip-style backdrop), dragging (`RegisterMover` / `RefreshMover`: a handle over the frame while unlocked, `SetUnlocked`, positions in the `positions` section), `NewScrollBar` (Pillars UI's) and `ShowCopyBox`. Some of it (media, `CreateInsetBorder`, `RegisterMover`) was for the old view and is unused since 2.0.0. Pillars UI-only calls (`RegisterAnchor`, `RegisterBoxPanel`, `IsModuleLoaded`) do nothing, so the Data Box placement never applies.
- `LootTracker/Data.lua`: the settings' defaults and the entries shown (scope, grouping, sorting, values), item tooltips, export, the reset popup.
- `LootTracker/Window.lua`: the window (the owner's design, from CRPGui): Blizzard's group loot history window as the model, `DefaultPanelFlatTemplate` with a scrolling list and a resize grip; in its title bar a close button (`collapsed`), a lock button (`locked`) and an arrow `LootTrackerMenu` (atlases `128-RedButton-ArrowDown` / `-Pressed`) opening a `MenuUtil` menu; a row per source with its portrait (`PlayerModel:SetCreature`, held still, shown only while its row is wholly inside the list) or icon, a click folding its loot, an X forgetting it, a row per item, a total under the list.
- `LootTracker/Settings.lua`: the settings (the same as CRPGui's Loot Tracker page), a canvas panel in Blizzard's options (`Settings.RegisterCanvasLayoutCategory`, else `InterfaceOptions_AddCategory`) with controls of our own, in a scroll frame; `/lt` and `/loottracker` (the game keeps `/loot` for its own loot window).
- `LootTracker/Media/PortraitRing.tga`: Pillars UI's portrait ring.

## Rules

- No combat log, no `GetSpellInfo` / `GetItemInfo` (vendor value is `C_Item.GetItemInfo`'s sell price). Guard secret values with `API.IsSecret` / `API.Plain`.
- With Pillars UI's or CRPGui's Loot Tracker module loaded (`PillarsUI_LootTracker`, `CRPGui_LootTracker`), this addon stands down (`ns.standingDown`, checked on every event): no tracking, its frame hidden.
- Saved data is its own (`LootTrackerDB` per character; `LootTrackerNames`, `LootTrackerPrices`, `LootTrackerSettings` account-wide); it never reads Pillars UI's (the owner's choice).
- Keep the README's settings table in step with the defaults in `Data.lua` and the controls in `Settings.lua`.
- Check syntax with `luac5.1 -p` on every Lua file before committing.
- Releases: bump `## Version` in `LootTracker/LootTracker.toc`.
